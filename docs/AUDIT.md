# Аудити лоиҳа (Phase 0) — аз рӯи 38 файли воқеӣ

Файлҳое, ки дида нашуданд: `pubspec.yaml`, `firestore.rules`-и воқеии шумо, `android/`, `web/`, Node-миграциҳо.

## Бозёфтҳо (аввал — хатари баландтар)
| # | Бозёфт | Ҳолат |
|---|---|---|
| 1 | `loginIndex/{login}` ҳангоми сохтани корманд/ширкат бе санҷиши мавҷудият навишта мешуд — админи як ширкат метавонист логини ширкати дигарро ғасб кунад | **Ислоҳ**: санҷиш дар код + rules (update манъ) |
| 2 | Ҳамаи филтрҳои ширкат танҳо дар клиент буданд; rules-и воқеӣ дида нашуд | **Ислоҳ**: `firestore.rules` пурра навишта шуд (тестҳо навишта шуданд, **иҷро нашуданд**) |
| 3 | Super Admin танҳо бо майдони `isSuperAdmin` дар users, ки аз клиент навишта мешуд | **Ислоҳ** дар rules: клиент ин майдонро гузошта наметавонад |
| 4 | Stage-ҳои ширкатҳои нав ID-и `${orgId}_${key}` доранд, вале `customers.stageId` калиди кӯтоҳ — kanban-и ширкатҳои нав мизоҷонро намефаҳмид; `save()` бо ID-и умумӣ байни ширкатҳо бархӯрд мекард | **Ислоҳ**: `PipelineStage.key` + `matches()` (ҳам калиди кӯтоҳ, ҳам ID-и кӯҳна) |
| 5 | Нест кардани stage-и «Мизоҷ шуд/Рад кард» closeDeal-ро мешикаст; мизоҷони stage-и нест шуда аз kanban нопадид мешуданд | **Ислоҳ**: stage-ҳои системавӣ ҳимоя; сутуни «Без стадии» |
| 6 | `closeDeal/rejectDeal` — batch бе санҷиши ҳолат: такрор/ду нафар ҳамзамон иҷро мекарданд | **Ислоҳ**: транзаксия + идемпотентӣ (false агар аллакай пӯшида) |

| 10 | «Рад шуд» дар deals_screen «Пӯшида» нишон дода мешуд | **Ислоҳ** |
| 11 | Stream-ҳо дар `build()` сохта мешуданд (аз нав обуна ҳар rebuild) | **Ислоҳ**: stream дар `initState` |
| 12 | Kanban: сутунҳои баланд overflow мекарданд | **Ислоҳ**: скролли амудӣ |
