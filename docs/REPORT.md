# Гузориши марҳилаи 1 (ростқавлона)

## Иҷро шуд (код навишта шуд)
- Ба Senova CRM иваз шуд: номи барнома, sidebar, экрани вуруд, title; нишони «S» (градиенти кабуд→сабз).
- Дизайн: торик + кабуд (`#2F80ED`) + сабз (`#22C55E`), шрифти Inter (ҳарфҳои тоҷикӣ дастгирӣ мешаванд).
- Се забон: **русӣ (пешфарз)**, тоҷикӣ, англисӣ; 173 калид дар ҳар се; забон дар профил нигоҳ дошта мешавад.
- Амният: `firestore.rules` (изолятсияи ширкатҳо, нақшҳо, claim, ширкати боздошташуда, journal), ҳимояи loginIndex, нест кардан — танҳо admin.
- RBAC: `Permissions` + нақши нав `viewer`; ғайрифаъол кардани корманд.
- Журнали амалҳо (auditLogs) + tab дар танзимот.
- Super Admin: боздоштан/фаъол кардани ширкат; сохтани ширкат дар як batch.
- CRM: ислоҳи stage-ҳо (key), идемпотентии closeDeal/rejectDeal, ҷустуҷӯ дар kanban/мулкҳо, сутуни «Без стадии», сделкаҳо бо номи мизоҷ/мулк, супориш бо мизоҷ, статуси мулк, dashboard нав (pipeline ≠ даромад, супоришҳои гузашта).

## Санҷида шуд (воқеан иҷро шуд)
- `scripts/check_project.py`: калидҳои тарҷума дар се забон, placeholder-ҳо, import-ҳо, рангҳо, баланси қавсҳо, `const`+`tr()` — **ҳамааш гузашт** (2 огоҳии бардурӯғ: `imkon-crm` — номи лоиҳаи Firebase; `AppColors._`).

## НАСАНҶИДА (дар муҳити ман Flutter/Dart/Node-пакетҳо/интернет набуд)
- `flutter analyze`, `flutter test`, `flutter build web/apk` — **иҷро нашуданд**. Эҳтимоли хатои компилятсия вуҷуд дорад; нахустин қадами шумо: `flutter analyze` ва ба ман хатоҳоро фиристед.
- `firestore-tests` ва `test/senova_test.dart` навишта шудаанд, вале **иҷро нашуданд**.
- Rules-ро бо лоиҳаи воқеии худ дастӣ санҷед (вуруд, claim, сохтани корманд/ширкат, super admin).

## Хатарҳои боқимонда
1. `loginIndex` get-и оммавӣ: email-и корбар бо донистани логин ошкор мешавад (username enumeration). Роҳи ҳал: Cloud Function callable.
2. Журнал аз клиент навишта мешавад (сохтакорӣ аз ҷониби аъзои ширкат имконпазир). Роҳи ҳал: Cloud Functions.
3. Маҳдудиятҳои тариф (maxUsers) ва санҷиши мӯҳлат танҳо бо server-side иҷро мешаванд — ҳоло нест.
4. Super Admin аккаунтҳои Auth-ро аз клиент нест карда наметавонад (ятим мемонанд).
5. Ҷустуҷӯ client-side; limit(1000) — барои ширкатҳои калон саҳифабандӣ лозим.
6. Нест кардани корманд аккаунти Auth-ро нест намекунад (вале профил нест → вуруд ғайриимкон).

## Иҷро НАШУД (аз master prompt) — бо сабаб
Ин қисмҳо дар як гузариш бехатар сохта намешаванд ва бе Cloud Functions/провайдери пардохт/тасдиқи бизнес ғайримумкин аст:
subscription ва пардохт, Cloud Functions (reminder, automation, webhooks), WhatsApp/Telegram/Instagram, CSV import/export,
custom fields, якчанд pipeline, модули саноати дуюм, push, backup автоматӣ, Crashlytics, муҳити staging/prod.
Қ. `docs/ROADMAP.md`.

## Қадами минбаъда
Фаза 1б: `flutter analyze` + ислоҳҳо → Cloud Functions (login lookup, audit, лимитҳо) → Фаза 2 (custom fields, саҳифабандӣ) → Фаза 3/4.

# Гузориши версияи 2

**Навишта шуд:** демо-режим (8 соҳа), шаблонҳои соҳа (stage, истилоҳот, маълумоти демо), танзимоти ширкат (модулҳо, номҳо, майдонҳои иловагӣ) бо редактори Super Admin, таҳрири мизоҷ, аниматсияҳо, UI-и пайвасти мессенҷерҳо, `functions/` (Telegram, Meta), rules-и нав + тестҳо.

**Санҷида шуд:** `scripts/check_project.py` (калидҳо, import-ҳо, рангҳо, қавсҳо, override-и соҳаҳо). `flutter analyze` / `flutter test` — **шумо бояд иҷро кунед** (дар муҳити ман Flutter нест). Версияи 1 дар компютери шумо бе хато гузашт.

**Санҷида НАШУД:** функсияҳои сервер (ҳеҷ гоҳ компил нашудаанд), rules-тестҳои нав, пайвасти воқеии Telegram/Meta, намоиши визуалии аниматсияҳо.

**Хатарҳо:** Meta App Review; webhook-и Meta бе санҷиши воқеӣ; `loginIndex` ҳанӯз email-ро ошкор мекунад; журнал аз клиент навишта мешавад; тарифҳо/лимитҳо ва пардохт нест; «номҳои ихтиёрӣ» як забона аст (барои ҳамаи забонҳо).

**Иҷро нашуд:** пардохт ва лимитҳои тариф, ҷавоб ба паёмҳо аз барнома, CSV, ҳисоботи давра, push, якчанд pipeline, саҳифабандӣ.
